How to add your files

  1. Open the files/ folder on GitHub and pick your subject folder (e.g. Quantum-Mechanics).
  2. Click Add file → Upload files and drag your file in. Give it a clear name like Griffiths-Ch2-Solutions_AliceW.pdf.
  3. Write a short message, choose Create a new branch and start a pull request (or commit directly if you have access), and submit.
  4. Once it is merged, the site rebuilds automatically and your file appears here within a few minutes.

Full guide, naming tips and rules: README.
